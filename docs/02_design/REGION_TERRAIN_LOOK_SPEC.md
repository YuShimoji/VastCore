## 1. 地形の成り立ち（断面）

硬い砂岩の層が崖になり、やわらかい泥岩の層が斜面や低い丘になる。硬い層が帽子になって下を守るので、台地（メサ）、それが痩せたビュート、さらに痩せた尖塔が残る（米国国立公園局 Capitol Reef・Canyonlands の解説）。

```
      平らな上面（帽子の硬い層。まばらな低木）
  ───────────────┐
                  │ 崖：硬い砂岩。縦の割れ目で柱や板に分かれる。黒い筋が流れる
                  │      層の厚さの例 329 ft＝約100 m（Colorado NM の Wingate）
                  ▒ アルコーブ：水がしみ出す、下の不透水の層との境目にできる暗いくぼみ
                   ╲
                    ╲ 斜面：やわらかい層。崩れた角ばった岩で覆われる
                     ╲   層の厚さの例 88 ft＝約27 m（同 Chinle）
                      ╲______ 棚：次の硬い層の上面。歩ける
                             │ 次の崖
                              ╲____ 涸れ川：いちばん緑が濃い
```

- アーチは、割れ目で薄い壁（フィン）になった岩に穴が開いた物。実寸の例として、Landscape Arch の開口幅は 306 ft（93.3 m）。Arches 国立公園は一方向の開口が少なくとも 3 ft あればアーチとして数え、水路や以前の水路をまたぐものを天然橋と呼ぶ。[NPS の実測例](https://www.nps.gov/articles/arch-rock-stars.htm)・[形成と分類](https://www.nps.gov/arch/learn/nature/geologicformations.htm)
- 細い峡谷は、川が硬い砂岩を真下へ削った物。深さと幅の比は 10:1 を超える。Zion の Narrows は壁の高さ約 1,000 ft、川幅 20〜30 ft。
- 尖塔は、直角に交わる縦の割れ目が削られて残る（Canyonlands の Needles。割れ目の深さ 40〜50 ft）。

## 3. 表面・植生・光

- 色: 赤と橙は鉄分（赤はヘマタイト、黄〜橙はリモナイト）。白い層は、後から鉄が抜けた砂岩。層ごとに色が変わる。
- 材質の用途は崖の岩・岩屑・砂と土・草や低木。傾き・高さ・流量・曲率で重ね分けるのは先行調査の案。現行の砂岩はメッシュを専用シェーダーで描き、地層の境目と岩屑・湿り気などを使う。Unity Terrain のレイヤー数はこの経路の制約に含まれない。写真素材への差し替えと自動の凹凸は [表面材質の設計](REGION_SURFACE_MATERIALS_SPEC.md)。
- 土の表面: 黒くこぶ状の生物土壌クラスト（地表の生物の被覆の 70〜80% に達することがある）。
- 植生: 台地の上はまばらな針葉の低木林。涸れ川沿いがいちばん密で、広葉の木。しみ出す水の所に小さな緑の群落。斜面は割れ目と日陰（Natural Bridges の解説）。
- 置き方: 密度のマップから置き、道と水の上は除く（Horizon Zero Dawn のスライド要約）。岩は曲率と崖の位置を手掛かりに置く（Ghost Recon Wildlands の記事）。
- 光と空気: 太陽の低さで割れ目と裾がどこまで読みやすくなるかは、この場面で比べる仮説。空・太陽・霞を合わせる技術上の手掛かりは5.3節。

## 4. 冒険の導線として見えるべき物

- 棚は、崖に沿って進む道になる。涸れ川は、谷を進む道になる。
- 崖は関門で、越えるのは、崩れた斜面・割れ目・段のある所。資料にある実例は、崖の面を降りて棚で分かれる道、深い割れ目に沿う道、はしごのある峠（Canyonlands・Zion のトレイルの説明）。
- アーチ・ビュート・尖塔は、遠くから見える目印。アルコーブと細い峡谷は、近づくと見つかる場所。
- 奥を遮って、歩くにつれて見せる（CEDEC 2017 の講演記事）。体系的な道筋の資料は取れていないので、ここは推定を含む。

### 5.2 写真に近い地表にする試験（製品への採用は未決）

UE の乾燥地サンプルはモアブで採取した岩と地表の高密度な形状・材質を使う。VastCore ではまず同じ地形の上で材質と小石を一つずつ替え、どの距離で差が出るかを調べた。[Epic の制作内訳](https://dev.epicgames.com/documentation/en-us/unreal-engine/valley-of-the-ancient-sample-game-for-unreal-engine)・[Landscape の材質混合](https://dev.epicgames.com/documentation/en-us/unreal-engine/landscape-materials-in-unreal-engine)・[Unity URP の Lit](https://docs.unity3d.com/6000.3/Documentation/Manual/urp/lit-shader.html)。

### 5.4 少ない手作業で別の地点にも使えるか

制作者の操作として想定する案は、地域の seed と地点を選ぶ → 砂岩用の素材・配置設定を呼ぶ → 遠中近をプレビューする、の3段。設定に持たせる候補は岩と植生の実寸、層の向き、傾斜・湿り気による配置と除外。地点ごとに手直しした内容は自動生成分と区別する。現在のメニューから一度に作れるのは既定の一場面で、この操作案を別の地域へ移すときの不足は下の実測に示す。

Epic の乾燥地の制作例では、撮影した岩を大小のまとまりに組み、同じ素材を別の組み合わせで配置している。PCG Biome の公式例では、再利用する素材・地形条件・配置の除外範囲を個別に設定して局所プレビューを行う。VastCore に持ち帰れるのは、**景観ごとに岩を一から置き直す手間を、素材の準備と再利用できる配置規則に分ける**という考え方。UE での制作例と Unity での実測は別に扱う。[Epic の乾燥地制作・Packed Level Instances](https://dev.epicgames.com/documentation/en-us/unreal-engine/valley-of-the-ancient-sample-game-for-unreal-engine)・[PCG Biome Core の構成](https://dev.epicgames.com/documentation/en-us/unreal-engine/procedural-content-generation-pcg-biome-core-and-sample-plugins-overview-guide-in-unreal-engine)

| 方法 | 初回に作るもの／別地点で繰り返す作業 | 比較で分かること |
|---|---|---|
| 現行の手続き生成を活かす | 開発担当が高さ場・局所の張り出し・転石の関係を1区画で作る。次の地点では同じ規則に seed と地図座標を渡す | 個別の岩の手置きは省ける。地層の向きや裾が違う場所でも同じ溝と山型の反復が出るなら、配置や断面の規則を見直す |
| 実寸の岩面を部品として配置する案 | 素材を選び、実寸・層の向き・接地位置・離れたときの軽い形を一度揃える。次の地点では局所の壁に合う部品を規則で選ぶ | 近景の欠けや割れを短時間で得られるか。継ぎ目・同じ形の反復・道を塞ぐ箇所の手直しを数える。参照候補の Rock Face 02 は幅4.9 m、約3万三角形、CC0 表示。苔や縮尺が乾いた崖に合うかも見る。製品への取込・採用は未決。[配布元の形状・材質・寸法](https://polyhaven.com/a/rock_face_02) |
| 細部を外して形を検証する案 | 同じ地形・光・視点で、縞や砂礫の細かな色を単色にした比較画を用意する。次の地点でも同じ表示条件を使う | 棚の張り出し、陰の奥行き、通れる幅が残るか。ここで形を読めるのに完成材質では消える場合は、次に材質の明暗と光を比べる。植生の実寸感は通常表示で確かめる |

**別の地点で実際に試した結果。** 256 km・1024² の seed 8 で `--mesa-sites` の先頭候補（X82.5 Y62.2）を選び、`--look all --look-center "82.5,62.2"` で撮った。6 km 窓の候補スコアは99%でも、内側約1 km の陸で帽子の岩が占める割合は0.1%。冒頭の図の下段では、seed 9 用の近景カメラが平地の向こうの崖を見ている。この例では、乾燥地を選ぶ処理と、そこで崖と足もとを撮れる視点を選ぶ処理に、別々の入力が要る。[候補の算出と座標指定](../../tools/RegionMapPreview/LookView.cs)

リポジトリ直下の PowerShell でこの地点を再現する。候補の順位は地形条件、遠中近の画像は簡易描画の結果。Unity の `view3d` は `-LookCenter X,Y` で同じ中心を指定できる。遠中近は [RegionLookSpec](../../Assets/Scripts/RegionMap/Core/RegionTerrainLook.cs) の固定値を保つ。

```powershell
dotnet run --project tools/RegionMapPreview -c Release -- --seed 8 --res 1024 --mesa-sites --look all --look-center "82.5,62.2" --out artifacts/region-map/mesa-site-check
```

**第4区切りの実画面（Unity 6000.3.6f1）。** 左から植生を隠した変更前、形状変更、植生込みの通常表示。中景では砂岩層の下に横に続く開口ができ、近景では天井の下面、暗い奥壁と足もとの緑、その外の岩塊が見える。遠くからの縦溝の反復、丸い裾、転石の平らな面は残る。[二地点の比較画像](../../Documentation/mesa-alcove-comparison.jpg)・[裾から棚への移動（左 seed 9、右 seed 8）](../../Documentation/mesa-alcove-walk.mp4)

通常メニューの `Region Terrain Look/Viewpoints` に `alcove-mid`・`alcove-near`・`alcove-shelf` が加わる。広域は高さ場を使い、内側の窓で岩壁の横の連続性・奥行き・両端の支えを調べる。選んだ1か所に洞窟試作の密度と Surface Nets を使い、地層の材質・座標を周囲と共有する。床を失った転石・草は表示から外し、現在の床に崩落岩としみ出し沿いの株を配置する。[適地の条件](../../Assets/Scripts/RegionMap/Core/RegionMesaAlcove.cs)・[局所の表示と追加視点](../../Assets/Scripts/RegionMap/View/RegionAlcoveView.cs)

| 入力（地図座標） | 通常表示と手間 | 場面生成／起動・撮影・終了を含む待ち |
|---|---|---|
| seed 9、X43.61 Y76.92 | 既定の中景で中央のビュートの裾に開口。崩落岩 32 個、しみ出し 79 株を自動配置 | 28.5 秒／65.9 秒 |
