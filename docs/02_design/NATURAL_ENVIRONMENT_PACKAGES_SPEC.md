# DS-014 自然地形パッケージ

地域の高さ場と座標を使い、海岸、洞窟、森林・密林・自然公園を作る。環境を移して使える地形部品、植生の形と配置条件、材質、接続寸法を一緒に整える。[SP-021](REGION_MAP_EXPLORATION_SPEC.md) 段5の景観と局所地形を対象にする。

本人指定（2026-11-28）。海岸は「全て欲しいですが、まずAから着手してください。推奨順で良いです。」。順は A 硬岩の岬と入り江 → C 岩礁とポケットビーチ → B 砂浜と砂丘。洞窟の最初は「A 崩落岩の裂け目と二層の石橋（推奨）」。制作途中の判断と実物・理想の差を、次のパッケージに反映する。

### 再生成

- 海岸の基準絵は、地域導出の候補から高低差の大きい岸、低い外洋岸、遮蔽候補を選ぶ。高さは岸から内陸1 kmまでの標高、海側の開きは0.5〜2 kmの7方向の遮られ方で比較する。簡易描画の俯瞰・遠中近と CSV が出る。

  ```powershell
  dotnet run --project tools/RegionMapPreview -c Release -- --seed 8 --coast-survey --out artifacts/region-map
  ```

- Unity の `Vastcore > Region Map > Rocky Coast Sample > Seed 8 / Seed 9` で海岸Aを開く。`Vastcore.RegionMap.Editor.RegionRockyCoastMenu.CaptureFromCommandLine` は `-regionSeed`、`-regionOut`、`-sunAltitudes` を受け、`-coastHeight`、`-coastShelfWidth`、`-coastShapeSeed`、`-coastPropsSeed` で崖・岩棚・Propsを再生成できる。
- 代表区間の前後比較は `Vastcore.RegionMap.Editor.RegionRockyCoastMenu.CaptureRockfallFromCommandLine` に同じ引数を渡す。前回Aと今回Aで、拡大地形の標高0 mを横切る岸を共有する。岸から沖まで外洋の連結水域に含まれることを確かめ、近景は水際から沖20 m・海面上3.4 mに置く。前後で遠・中・近のカメラ、太陽の方向と高度、波の時刻を固定する。
- 岩肌と水際の仕上げを比較する場合は `Vastcore.RegionMap.Editor.RegionRockyCoastMenu.CaptureAppearanceFromCommandLine` に `-regionSeed`、`-regionOut`、`-sunAltitudes` を渡す。通常の `Seed 8 / Seed 9` メニューから現行の場面を開き、`0da4d2a` 時点の代表区間と同じ視点で撮る。太陽38°では、水面と礫の接地を見るため岸に沿う低い視点も撮る。
- 海岸Cは `Vastcore > Region Map > Pocket Beach Sample > Seed 8 / Seed 9`。同じメニューの `Low Tide` と `High Tide` で潮位を切り替える。`Vastcore.RegionMap.Editor.RegionPocketBeachMenu.CaptureFromCommandLine` に `-regionSeed`、`-regionOut`、`-sunAltitudes` を渡すと、通常メニューから開いて遠・中・潮だまりの近景を2水位で撮る。
- Cの代表カットは `Pocket Beach Sample > Seed 8` を開き、`Low Tide` と `Concept View` を選ぶ。`Vastcore.RegionMap.Editor.RegionPocketBeachMenu.CaptureConceptFromCommandLine` は同じメニューから1枚を撮る。
- 海岸Bは `Vastcore > Region Map > Dune Beach Sample > Seed 8 / Seed 9`。`Low Tide` と `High Tide` で水際と濡れ砂が一緒に移る。`Vastcore.RegionMap.Editor.RegionDuneBeachMenu.CaptureFromCommandLine` に `-regionSeed`、`-regionOut`、`-sunAltitudes` を渡すと、通常メニューから遠・中・漂着帯の近景を撮る。

## 洞窟Aの接続と部品

屋外座標と入口は既存の崖試作を使う。入口 → 曲がりのある通路 → 二層の広間 → 奥の壁を断面でつなぎ、石橋・上り下り・下段を共通にする。入口・曲がり・広間・終端の断面は中心線、床高、幅、天井高を共有する。各接続では同じ断面頂点を使い、歩行用のメッシュも共有する。

`layered-cave` の `Vastcore > Region Map > Open 3D Cliff And Cave Prototype` と `(Long Passage)`。Play で WASD、矢印または右ドラッグで見回し、入口付近の E で出入りする。長い通路版では入口から広間までの曲がりと距離、奥の形、周辺の岩を変える。[現実の崩落岩の隙間と外光](https://www.nps.gov/places/balconies-cave.htm)

比較した案は、旧水路と石灰洞（低い水路と乾いた棚、滴下・堆積の材質）、海食の入口と乾いた奥室（波の当たる入口に限って海岸材を共用）。最初のAでは、崩落の向き、石橋の床、頭上の安全な余白を優先する。[石灰洞の形成条件](https://www.nps.gov/cave/learn/nature/cave.htm)

## Propsを拡充する順序

1. 共通の棚岩・礫・岩屑を再利用する。幅、粒径、露出面、斜面の向きで役割を与える。海岸Aの流木は高い棚の漂着帯に寄せ、洞窟の低い通路には岩片の密集を避ける。
2. 画面で不足した役から追加する。海岸は波で丸くなった礫、濡れた棚の小岩、岸に沿う漂着群、塩風を受ける草。洞窟は岩の壁際、薄い崩落片と天井片、支点付近の岩塊、奥の部屋の目印。支持面と通路幅を決めてから形を増やす。
3. 試作で配置を前後比較し、足りない役と再利用できた役を確認してから DS-011 に登録する。出所、材質、LOD、ピボット、通行判定を FBX と一緒に確認する。Player にはモデルを含める参照を持たせ、Editor の読込結果と比較する。

形状と配置には別の seed を持たせる。プロファイルは地質・外洋への開き・岩棚幅・Props密度などの景観差、seed は形と個体の組み合わせを受け持つ。入口、接合面、主動線は装飾の seed と独立させる。

#### 海岸Aの岩盤と水際の仕上げ

前回は写真材質を指定しても頂点に重みがなく、岩面の色と法線が効いていなかった。細密メッシュに重みを渡し、崖と棚は既存の `rock_boulder_cracked`、浜は `rocks_ground_06` を使う。海面からの高さで濡れを変え、水際の緩斜面には既存FBX `wash_sorted_cobbles` を小群で配置する。崖直下の角礫から浜の丸礫へつなぐ。横切れ目の最初の試作で鋭い三角が出たため、傾いた面の付近だけ勾配を弱め、縦の節理に短い段差を交差させる方式に変えた。

丸礫は海面上0.09〜1.27 m、傾斜25°以下を配置候補とする。群れを斜面に沿わせ、礫ごとにLOD0・1の底を地表へ2.4 cm沈める。最初は群れの端で影と礫が離れて見えたが、石ごとの接地後に収まった。通常メニューのseed 8・9で丸礫33・25群を確認し、遠・中・近を太陽4条件、水際視点を38°で前後撮影した。[NPSの実景、完成想定図、Unityの前後52枚とメニューの画面](<D:/AI-Runs/VastCore/coast-and-cave/refinement/coast-appearance.html>)

近景で岩肌の凹凸と、岩盤・濡れた地面・丸礫の区別が付いた。完成想定図に比べて中景の縦溝は大きく、岩棚の横の張り出しが弱い。礫も浜全体を埋める厚みには達しておらず、水際の泡の間隔が揃って見える。別地点では塗り分けと水際の高低差に従う配置を再利用し、礫の密度と岩棚の形を独立に変える。

### 海岸C 岩礁とポケットビーチ

本人がAの比較を確認し、Cの代表区間を指定した。外洋岸の seed 8・9 の低い候補に、岬に挟まれる砂浜と湾口の離れ岩を組んだ。沖の岩礁が波を受け、湾奥に砂が集まる関係を [NPSのSand BeachとOld Soaker](https://www.nps.gov/articles/000/geologic-story-of-sand-beach.htm)、低い岩棚に水が残る形を [USGSのPoint Reyes](https://www.usgs.gov/media/images/a-photo-tide-pools-0) で参照した。

Aの割れ棚・丸礫、岩肌 `rock_boulder_cracked` と礫ごとの接地を再利用した。岩棚は傾斜27°以下の支持面に低く埋め込み、平らな面にも岩肌を水平投影する。`Ground054` の砂は湾内に続け、丸礫は砂と岩の境界に寄せる。水面は最終地形から水深・底質・外洋への開きと連結を取り、溢れ口の周りは岩棚を空ける。低潮 −0.55 mでは海と別の水面（＋0.27 m）が凹部に残り、満潮 ＋1.02 mでは溢れ口を通って海とつながる。

通常メニューを使い、2 seed・遠中近・太陽4条件・2水位で、岩棚を仕上げる前後の48組とメニューを開いた直後の2枚を撮った。seed 8・9の棚は31・43点、丸礫は15・13群。露出した砂浜の集計面積は低潮から満潮で2,881→1,342 m²、3,090→1,454 m²。地域生成後の構築は494・390 ms（Unity Editor、各1回）。[実景・完成想定図・固定視点の前後・低潮と満潮](<D:/AI-Runs/VastCore/coast-and-cave/pocket-beach/index.html>)

初回は手前の斜面が潮だまりを隠したため、視点を固定して手前を低い波食棚にした。浅い段に割れ棚を埋め、短く途切れる節理を重ねると、岩盤の縁と水が読みやすくなった。地形自身の影が対岸に縦線を作ったため、Cでは地形メッシュの影の投射だけを切り、棚岩の接地影を残す。想定図との差は、対岸の張り出す岩層の少なさと、浅瀬に残る反射の周期・水底の見え方。

### 海岸B 砂浜と砂丘

### 湿潤な密林の仕上げ
