# DS-014 自然地形パッケージ

地域の高さ場と座標を使い、海岸の景観と、地上の入口から出入りできる別マップの洞窟を作る。環境を変えても使える地形部品、配置条件、材質、接続寸法を一緒に整える。[SP-021](REGION_MAP_EXPLORATION_SPEC.md) 段5の景観と局所地形を対象にする。

本人指定（2026-11-28）。海岸は「全て欲しいですが、まずAから着手してください。推奨順で良いです。」。順は A 硬岩の岬と入り江 → C 岩礁とポケットビーチ → B 砂浜と砂丘。洞窟の最初は「A 崩落岩の裂け目と二層の石橋（推奨）」。制作途中の判断と実物・理想の差を、次のパッケージに反映する。

## 海岸の形と素材

| 方向 | 遠・中・近で見るもの | 実装と負荷の見込み |
|---|---|---|
| A 硬岩の岬と入り江 | 岬の輪郭。節理の方向で割れる岩盤と、湾に向かって低くなる棚。水に濡れた低い岩、崖の下の角礫、湾奥の丸礫と漂着物 | 高さ場の岸近くに棚・崖を作る。岩の硬さと外洋への開きで連続する面と途切れを作る。岩面と局地的な泡が負荷の中心。[遠 Schoodic Point](https://www.nps.gov/places/schoodic.htm)・[中 Monument Cove](https://www.nps.gov/acad/learn/nature/images/IMG_5048_1.JPG)・[近 Schoodic の岩脈](https://www.nps.gov/articles/images/cropped1.jpg) |
| C 岩礁とポケットビーチ | 沖の低い岩礁と湾奥の砂。波食棚の凹み。浅い砂底・暗い礁底・低い潮だまり | Aの岩と水深を再利用し、砂が集まる場所と孤立した水面を追加。岩棚と水面が重なる画素、2水位の撮影が増える。[遠 Sand Beach](https://www.nps.gov/articles/000/geologic-story-of-sand-beach.htm)・[中 Point Reyes の波食棚](https://www.usgs.gov/media/images/a-photo-tide-pools-0)・[近 Olympic の潮間帯](https://www.nps.gov/olym/learn/nature/tidal-life.htm) |
| B 砂浜と砂丘 | 広い緩斜面と砂丘の稜線。鏡面に近い濡れ砂と漂着帯。裸砂の間に塩風に沿う草の群落 | 低地を選び、砂浜から砂丘へ連続した断面を作る。草の描画距離と濡れ面の画素が負荷の中心。[遠 High Head](https://www.nps.gov/caco/learn/nature/sand-dunes.htm)・[中 Cape Cod Beach](https://www.nps.gov/caco/learn/nature/beaches.htm)・[近 砂丘の植生](https://www.nps.gov/caco/learn/nature/images/Nblinick_8004659.jpg) |

海は外周につながる水域を選ぶ。波の白さ・浅瀬・濡れ帯は、地面の高さとは独立した海面で表現し、深度・外洋への開き・岩底と砂底で変える。岩の張り出しが必要になった箇所は、承認済みの局所体積の範囲で扱う。[NASA 浅瀬の底質・水深](https://science.nasa.gov/earth/earth-observatory/landsat-plumbs-the-shallow-depths/)・[NOAA 波の屈折と湾の空撮](https://repository.library.noaa.gov/view/noaa/43643/noaa_43643_DS1.pdf#page=39)

### 再生成

- 海岸の基準絵は、地域導出の候補から高低差の大きい岸、低い外洋岸、遮蔽候補を選ぶ。高さは岸から内陸1 kmまでの標高、海側の開きは0.5〜2 kmの7方向の遮られ方で比較する。簡易描画の俯瞰・遠中近と CSV が出る。

  ```powershell
  dotnet run --project tools/RegionMapPreview -c Release -- --seed 8 --coast-survey --out artifacts/region-map
  ```

- Unity の `Vastcore > Region Map > Rocky Coast Sample > Seed 8 / Seed 9` で海岸Aを開く。`Vastcore.RegionMap.Editor.RegionRockyCoastMenu.CaptureFromCommandLine` は `-regionSeed`、`-regionOut`、`-sunAltitudes` を受け、`-coastHeight`、`-coastShelfWidth`、`-coastShapeSeed`、`-coastPropsSeed` で崖・岩棚・Propsを再生成できる。

## 洞窟Aの接続と部品

屋外座標と入口は既存の崖試作を使う。入口 → 曲がりのある通路 → 二層の広間 → 奥の壁を断面でつなぎ、石橋・上り下り・下段を共通にする。入口・曲がり・広間・終端の断面は中心線、床高、幅、天井高を共有する。各接続では同じ断面頂点を使い、歩行用のメッシュも共有する。

`layered-cave` の `Vastcore > Region Map > Open 3D Cliff And Cave Prototype` と `(Long Passage)`。Play で WASD、矢印または右ドラッグで見回し、入口付近の E で出入りする。長い通路版では入口から広間までの曲がりと距離、奥の形、周辺の岩を変える。[現実の崩落岩の隙間と外光](https://www.nps.gov/places/balconies-cave.htm)

比較した案は、旧水路と石灰洞（低い水路と乾いた棚、滴下・堆積の材質）、海食の入口と乾いた奥室（波の当たる入口に限って海岸材を共用）。最初のAでは、崩落の向き、石橋の床、頭上の安全な余白を優先する。[石灰洞の形成条件](https://www.nps.gov/cave/learn/nature/cave.htm)

## Propsを拡充する順序

1. 共通の棚岩・礫・岩屑を再利用する。幅、粒径、露出面、斜面の向きで役割を与える。海岸Aの流木は高い棚の漂着帯に寄せ、洞窟の低い通路には岩片の密集を避ける。
2. 画面で不足した役から追加する。海岸は波で丸くなった礫、濡れた棚の小岩、岸に沿う漂着群、塩風を受ける草。洞窟は岩の壁際、薄い崩落片と天井片、支点付近の岩塊、奥の部屋の目印。支持面と通路幅を決めてから形を増やす。
3. 試作で配置を前後比較し、足りない役と再利用できた役を確認してから DS-011 に登録する。出所、材質、LOD、ピボット、通行判定を FBX と一緒に確認する。Player にはモデルを含める参照を持たせ、Editor の読込結果と比較する。

形状と配置には別の seed を持たせる。プロファイルは地質・外洋への開き・岩棚幅・Props密度などの景観差、seed は形と個体の組み合わせを受け持つ。入口、接合面、主動線は装飾の seed と独立させる。
