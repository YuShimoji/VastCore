## 5. 構成

```text
Assets/Scripts/RegionMap/
  Vastcore.RegionMap.asmdef            （参照: UnityEngine.UI のみ）
  Core/   UnityEngine に依存しない C#（生成・描画・地点・探索の判定）
  View/   RegionExplorer（探索画面）、RegionMapTexture
  Editor/ Vastcore.RegionMap.Editor.asmdef、メニューとバッチ入口、画面確認用スモーク
Assets/Scenes/RegionExplorer.unity     探索画面のシーン（カメラと RegionExplorer だけ）
Assets/Tests/EditMode/RegionMapTests.cs
tools/RegionMapPreview/                Core を dotnet で直接コンパイルして PNG を書き出す確認用コンソール
scripts/region-map.ps1                 Unity のバッチ入口（setup / explore / play）
```

`Core/` は Unity の asmdef と `tools/RegionMapPreview` の両方から同じソースをコンパイルする。絵の調整は Unity を起動せずに数秒で回せる。既存の `Vastcore.Terrain` などへは依存しない（Deform・ProBuilder を巻き込まないため）。

### 生成の流れ（`RegionGenerator.Generate`）

1. `BuildBase`: ドメインワープした fBm で海陸を決め、外周は必ず海にする。山脈帯（ridged）と平野のマスクから隆起の強さを作る。
2. `Evolve`: Priority-Flood で窪地を埋めつつ下流→上流の順序を得て、流量を累積し、陰解法の stream power 侵食・斜面の上限（安息角）・斜面拡散を反復する。半解像度で反復の3/4、残りを全解像度で行う。「低い順に取り出す」待ち行列は高さ5mmごとの箱の列で持つ（`FlowRouter`。二分ヒープより速く、取り出す順は同じ）。
   - 流れ先は8方向から1つ選ぶが、比べ方をセルごとに決まった量だけずらし（`RegionSpec.FlowJitter`）、侵食の前と解像度を上げた直後に細かな凹凸を足す（`RoughnessMeters`）。これが無いと、なめらかな斜面で流れが平行な直線の束になり、そのまま溝として刻まれる。ゆらぎは seed から決まる固定値で、反復のたびには変わらない。
3. `BuildClimate`: 緯度と標高（6.5℃/km）から気温、西風が海で湿り陸と山で雨を落とす掃引から湿り気（雨陰が出る）。
4. `BuildRivers` / `ClassifyBiomes`: 流量のしきい値で川、気温×湿り気×標高×斜面でバイオーム。
5. `RegionSiteGenerator.Populate`: 候補点を地形で採点し、種類ごとに間隔を空けて選ぶ。

同じ `RegionSpec` からは同じ地域・同じ地点が出る（テストで固定）。

### 描画（`RegionMapRenderer.Render`）

気温×湿り気の色表の補間、北西315°からの陰影、落ち影、海の水深色、川、雪、雲と雲の影。`RegionMapStyle` は Satellite（写真風）/ Atlas（地図帳風）/ Relief（起伏を強調）。出力は RGBA32（北西の角から行順）。

衛星写真風（本人が選んだ様式）だけが持つ処理:

- 光: 直射光（やや暖色）と空からの光（青み）を分けて足す。日陰は黒く潰れず青黒くなる。
- 陸の色: 植生のむら（広いまとまり・細かなまだら・1セルごとの粒）と谷底の湿りを湿り気へ足してから色表を引く。急斜面は岩肌、森の斜面は岩が出にくい。雪の境目はむらを持つ。
- 川: 流量から幅と濃さを決めた被覆率を作り、軽くぼかす（`BuildRiverCoverage`）。細い川は薄くしか写らない。
- 海: 深い所は暗い紺、明るい青緑は岸のごく近くだけ。細かい模様は向きを回しながら重ねるノイズ（`RegionNoise.FbmTurned`）で作り、升目を出さない。
- 雲: `RegionClouds` が、上下左右のつながる（繰り返せる）雲の層を半分の解像度で作る。大きなまとまり・もこもこした塊・高い所の薄い筋雲を重ね、量は `RegionRenderOptions.CloudCover`（既定 0.58）で決まる。PNG 書き出しでは地図へ描き込み、探索画面では地図へ描き込まずに雲と影の2枚を上に重ねて流す。

## 6. 探索のルールと、ゲームを載せる入口

- 地図座標は X・Y とも 0〜100。X は東へ、Y は南へ増える。高さ（m）は `RegionData.HeightAtMap`。
- `ExplorationSession.Search(x, y)`: いちばん近い未発見の地点との距離で `Found`（2.5以内）/ `Strong`（8以内）/ `Faint`（18以内）/ `None` を返し、`Found` なら発見済みに加える。距離の値は調整用の公開フィールド。
- `ExplorationSession.Sense(x, y)`: 回数を消費せずに反応だけを見る。
- `SaveDiscoveredIds()` / `Restore(ids)`: 発見済みの地点 ID を保存・復元する（保存先は載せるゲームが決める）。
- `RegionExplorer`（MonoBehaviour）: `IsReady`、`Region`、`Session`、`CursorMapPosition`、`MoveCursor(x, y)`、`SearchAtCursor()`、`NextRegion()`、`NextStyle()`、`NextCloudOpacity()`、`CloudLevel`、`CloudDrift`。
- 探索画面の操作: 地図を左クリックでカーソル移動、Space / Enter / ボタンでサーチ、矢印キーで微調整、ホイールで拡大、右または中ドラッグで地図を動かす。「雲」ボタンで 濃い → 薄い → なし（衛星写真の時だけ）。雲は東南東へ、地図の幅を420秒で横切る速さで流れる（`_cloudCrossSeconds`）。

## 8. 既知の制限

- 湖は生成されない（窪地を毎回埋める）。`RegionBiome.Lake` と `LakeDepth` は場所だけある。
- なだらかな平野に薄い平行な筋が残る（山地の平行な溝と海の升目は2026-11-21に解消）。
- 探索画面の知らせの帯は3〜8秒で消える（生成中・描き直し中・エラーは出したまま）。出ている間は地図の南端に重なる。
- 反応の表示（弱い・強い）は方角を示さない。強い反応の範囲（半径8）は発見の範囲（半径2.5）の約10倍の面積で、その中は総当たりになる。
- 反応の表示は直前のサーチの結果で、カーソルを動かしても次のサーチまで変わらない。
- 生成の下地・気候と描画・雲は行ごとに並列で計算する。侵食は1本のスレッドで、生成時間の大半を占める。探索画面は開始時に生成が終わるまで待つ（Unity Editor で約9〜11秒。ビルドした Player では未確認）。
- 地点の中身、発見後の遷移、音、演出、保存の画面は無い。
- 探索画面の文字は OS のフォントを使う（Windows で確認）。他の環境の表示は未確認。
- 画面は 1920×1080 を基準に高さへ合わせて縮む。縦長の画面は未対応。
